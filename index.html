SysCore Programming Language

A fast, lightweight C++ interpreted scripting language built from scratch. Run interactive commands or execute .sc scripts natively on Windows, macOS, and Linux.

Download for Windows (.zip) Download for macOS (.zip) Download for Linux (.zip) View Source on GitHub

// Quick Start

Windows
  • Extract SysCore.zip and run register_sc.reg once.
  • Double-click Hello world!.sc or open SysCore.exe.
macOS & Linux
  • Extract SysCore-macOS.zip or SysCore-Linux.zip and open Terminal in the folder.
  • Run chmod +x SysCore && ./SysCore "Hello world!.sc".

// Built-in Functions

Python-inspired utilities built into the SysCore runtime:

ask() size() to_text() to_num() loud() quiet() pos() low() high() pwr() roll() wait() kind() wipe()

// Example: demo.sc

demo.sc 
create ("=== Welcome to SysCore ===") text
let user = ask("Enter your name: ")
create ("HELLO, " + loud(user) + "!") text

let lucky = roll(1, 100)
create ("Your lucky number: " + to_text(lucky)) text
